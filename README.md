# Fast.QRcode

A quick and easy tool for instantly generating a QR code in `.png` format from a website

<img width="500" height="600" alt="image" src="https://github.com/user-attachments/assets/ecac851d-8a9a-4aa1-aa3e-9e0ca628fa9f" />


This can be used to create QR codes for downloading files ( .cia, .exe, etc.) or redirecting to a URL

This tool uses Python; be sure to install the dependencies with these commands

pip install qrcode[pil]
or
pip install qrcode
pip install pillow
